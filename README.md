# openMotion

给 sticker 使用的可复用视频模板库：保存实际可取得、许可允许再分发的原生源码，以及全量候选的下载和运行状态。先核对源码，再选择模板，再按本期文案制作。

## 当前覆盖

2026-11-04 核对了 [MotionGit 官网](https://motiongit.com/templates) 的全部3页、60个条目，以及 [官方GitHub合集](https://github.com/motiontemplates/all) 的84个模板。按发布者数字ID关联官网改名条目，保留历史条目，合并后共 **100个模板索引**，另收录 **17个仅Demo项目**。本轮新增28个索引；官网60/60、官方合集84/84均已覆盖。完整逐项证据见 [覆盖核验](catalogs/coverage-audit-2026-11-04.json)。

实际已镜像 **10个模板、11个源码变体**；索引收录不代表取得源码。其余模板保留真实官网入口、Demo、版本、下载条件及许可，登录或禁止模板再分发的项目不会被当作可运行源码。个人Key与签名包保存在Git外。

此前本地已取得的9套新增MIT作者发行源码本轮一并同步到GitHub，保留原始发行包、许可、来源和逐文件摘要。源码静态验证不等于运行或渲染验收；官网新版与本地旧版分别记录，已确认项目继续绑定原版本。

这是独立整理库，不代表MotionGit或作者背书。第三方素材与模板代码分别遵守各自许可；本仓库保持私有。

## 使用

只需Python3即可检查索引，不会安装依赖、生成素材、调用收费服务或运行模板代码：

```bash
python3 scripts/library.py list --ready
python3 scripts/library.py show 385712
python3 scripts/library.py verify
```

`show`提供源码目录、原始包、入口、预览和许可。`verify`核对原始ZIP、全部源码文件哈希与来源身份；明文作者发行还绑定实际release、manifest、integrity和脱敏交付证据，不能用虚构Git commit代替。**静态验证通过不等于已完成依赖安装或视频渲染验证**。真正制作前读取对应模板的 `00-START-HERE.md`、manifest、素材合同和依赖说明，进行代码/依赖检查后在独立实例目录运行。不在 `templates/` 内改本期内容，保留原始包与来源。

候选完整数据见 [catalogs/templates.json](catalogs/templates.json)，来源/许可审计见 [catalogs/audit-summary.md](catalogs/audit-summary.md)。源码获取状态为false的条目可以展示为候选，但不能冒称已导入或直接开始样片。

## 与 sticker 衔接

1. 用户先填原创标题；助手起原创文案框架，然后等待用户填改写文案、30字以内简介和5个标签。
2. 用户明确用当前稿制作后，冻结输入，取得真实声音及时间轴。
3. 视觉编排阶段展示三个匹配本期主题的实际模板预览、名称/编号、版本、许可、素材要求和源码状态；随完整镜头计划一起请用户选择确认。
4. 选中模板后核对实际原生源码、入口与哈希；用户确认编排后才制作样片。缺源时等待或明确讨论替代方案，不把看Demo后的重写称为套用。
5. 样片确认后制作全片；发布包复用用户简介和标签，不再自动生成或改写。

本库目前有10个模板取得完整源码，可以按叙事需要选择不同模板与DEEP STAGE模块；**这些导入尚未进行模板运行与渲染验收**。推荐时必须说明真实源码、依赖与运行验证状态，不能把静态导入标成样片通过。运行规则见 [docs/sticker-integration.md](docs/sticker-integration.md)。

## 许可与后续导入

- 仓库自写索引工具/说明采用 [MIT](LICENSE)。第三方模板和素材沿用各自目录中的许可证，不统一重标为MIT。
- 镜像的385712保留作者原始MIT文本、OFL字体与品牌/素材声明，来源commit、公开下载URL、包SHA与逐文件hash可查。
- 未镜像条目只记录事实性名称、来源链接、版本与条件，不复制其禁止再分发的模板包、个人Key或未授权Demo媒体。
- 新源码必须能通过正常公开下载或已授权途径取得，并核对该确切版本的再分发许可。个人下载包的身份/Key不能放进Git仓库；也不通过删除Key、破解保护或伪造下载资格取得源码。
- 更新时新增或显式修订版本及来源哈希，保留旧项目依赖，不自动将上游“最新版”替换进已确认视频。

仓库不自动运行上游程序、不包含定时同步或收费API调用。需要导入更多模板时，先补齐其许可与实际下载条件，再更新目录和审计记录。
