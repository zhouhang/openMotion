## 可复用的风格与动作

- 三套舞台：灰白柔光棚景、暖木桌、纵深机房。质感依赖背景明暗、物体材质、接触阴影与前后景关系。
- UI 系统：黑白聊天界面、胶囊标签、角色色、微型编号、柔和投影。
- 动作：分字模糊变清晰、图层错峰进场、新卡接管/旧卡退后、打字和光标、焦点推近、路径绘制和沿弧线传输。
- 语义场景：聊天与角色对照、多角色协作汇总、计划清单、一人一台设备、终端权限、云端中转、支付面板、权益双卡。

## Remotion 可行性

Remotion 可以驱动所有 UI、标题、路径、时序与合成。大量立体物件在原片保持固定视角，可用有使用权限的透明资产与 2.5D 变换；需要自由视角/光照/形变再用 Three.js。若要求连木纹、机房、设备与角色也都零素材、纯程序生成，成本会显著增加。

优先实现 `SoftStudioStage`、`ChatThread`、`FileTransferArc`、`BenefitPairCards`。所有新单元应包含参数 schema、时长/阅读容量、字体和素材来源、可编辑源码、runtime 入口、版本、预览与真实渲染回执。
