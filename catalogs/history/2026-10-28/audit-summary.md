# Public-template audit and mirror boundary

The official catalogue snapshot contains 72 unique template IDs and 74 demo cards, plus one preview-only project. These counts describe the directory; they are not source-code coverage.

The pinned upstream catalogue is https://github.com/motiontemplates/all/commit/beb80cdacafb0b4d9d736caf3e2a8997e97a6961. Its `openSource` claims were checked against the actual public repositories and official template detail pages.

| Verified observation | Count |
| --- | ---: |
| Complete public source templates imported | 1 |
| Language variants of that source | 2 |
| Linked GitHub landing sites without template implementation | 37 |
| No linked source repository | 34 |
| Official MIT code declarations, subject to separate assets | 24 |
| Personal/noncommercial templates prohibiting redistribution | 21 |
| Commercial-output templates prohibiting template redistribution | 27 |

Only 385712, the Kinetic Tech public edition v0.2.7-open-beta, is imported. Its Chinese and English public ZIP packages each contain 331 files and 24 implementation files. Both download hashes match the pinned upstream PUBLIC-EXPORT.json. The source entry is adapter.py; it was not executed. Dependencies were not installed.

MIT code is kept with its original copyright and license. Fonts keep their SIL OFL notices. MotionGit brand assets have a separate unchanged-redistribution permission; no trademark ownership or endorsement is claimed. All files remain byte-identical to the public export, with importer provenance files added separately.

The other 71 source templates are not obtained. Public official detail pages show 44 login routes, 15 social-support-gated routes and 12 temporarily unavailable routes after treating 385712 as a separate public export. These conditions are recorded independently of the redistribution restrictions. A free price, a complete demo, or a README page is not source redistribution permission.

The official 643842 page declares MIT code but distributes an authenticated personal package containing an API key. No personal package was accessed or copied. Its third-party illustrations, fonts and models retain their own licenses.

The upstream `motiontemplates/all` directory itself has no root LICENSE. This repository's catalogue is a new factual inventory of IDs, names, observed licensing/access states and source links; the upstream explanatory catalogue text and demo videos were not copied into it.

No template code was run, no login/payment/support gate was bypassed, and no private account key was read or published. The imported public export passed archive-path checks and a static literal-secret screen. This is a provenance/import check, not a security certification of executable source.
